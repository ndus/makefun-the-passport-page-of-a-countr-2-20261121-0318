A dependency-free Python renderer creates an invented Vesperalian passport spread with security-paper texture, portrait, aligned identity fields, and a coherent sequence of travel stamps. The night-only entry condition and moon-credit fee mark the republic's dusk-to-dawn civic life.

## Run it

```sh
python3 main.py
```

It writes `entry.png` to `/output` or `$MAKEFUN_OUTPUT_DIR`.
